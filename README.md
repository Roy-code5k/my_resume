## 🚀 How to Use

### Option 1 — Overleaf (Recommended)
1. Go to [overleaf.com](https://www.overleaf.com)
2. Click **New Project → Upload Project**
3. Upload `main.tex`
4. Hit **Recompile** — done

### Option 2 — Local Compilation
Make sure you have a LaTeX distribution installed ([TeX Live](https://tug.org/texlive/) or [MiKTeX](https://miktex.org/)):

```bash
git clone https://github.com/Roy-code5k/resume.git
cd resume
pdflatex main.tex
```
